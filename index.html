Understanding HTTP (Hypertext Transfer Protocol)

HTTP is the foundational protocol used by the World Wide Web to transfer data between clients (such as web browsers) and servers. When a user requests a web page, the browser sends an HTTP GET request, and the server returns an HTTP response containing headers, status codes (like 200 OK), and the requested resource body.

Key components of HTTP requests include:

  • Headers: Metadata like Content-Type, User-Agent, and Host.
  • Status Codes: 200 OK (Success), 404 Not Found, 500 Server Error.
  • Persistent vs Non-Persistent: Persistent HTTP reuses TCP connections for multiple media requests, whereas Non-Persistent opens a new connection per item.
